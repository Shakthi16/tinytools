# Tiny Tools

A colorful collection of everyday tools for creators, developers, and curious people. Small tools. Big possibilities.

## Features

- **Rich Catalog of Tools**: Text tools, developer utilities, formatters, generators, converters, and more.
- **Client-Side First**: Fast in-browser processing keeps data private and responsive.
- **Neo-Brutalist Design**: Vibrant colors, bold borders, retro-modern typography, and micro-interactions.
- **Account & Favorites**: Save favorites, manage your profile, and personalize your workspace.

## Development

Prerequisites: Node.js (or Bun) installed on your system.

```sh
# Install dependencies
bun install
# or
npm install

# Start local development server
bun run dev
# or
npm run dev

# Run tests
bun test

# Build for production
bun run build
```
