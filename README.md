# ⚡ TINY TOOLS

> **Small tools. Big possibilities.**  
> A colorful, neo-brutalist suite of **53+ everyday utilities** for creators, developers, designers, and students.  
> **100% Client-Side. Zero server uploads. No accounts required. Instant live results.**

---

## 🎨 The Neo-Brutalist Philosophy

Tiny Tools is designed with bold visual expression and absolute user privacy:
- ⚡ **High Contrast & Hard Shadows**: Retro-modern borders (`3px solid var(--border)`), vibrant accent fills, and physical click micro-interactions.
- 🔒 **Zero File Uploads**: Every PDF, image, audio file, snippet, and hash is processed **100% inside your browser** via HTML5 Canvas, Web Audio, Web Crypto, and local WebAssembly.
- ⚡ **Zero Latency**: Real-time reactive updates as you type or drag-and-drop. No waiting for round-trip server responses.
- 🆓 **No Paywalls or Hidden Watermarks**: Free for everyone, forever.

```
│   ├── routes/

│   │   └── tools/$toolId.tsx     # Dynamic Tool Route with Dedicated Instructions
│   └── styles.css                # Global Neo-Brutalist CSS Tokens & Utility Classes
├── public/                       # Static Assets & SVGs
├── package.json
└── vite.config.ts                # Vite + TanStack Start + Nitro Cloudflare Preset
```

### Core Technologies
- **Framework**: [TanStack Start](https://tanstack.com/start) + [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Build Engine & Preset**: [Nitro](https://nitro.unjs.io/) configured for `cloudflare-module` (Workers & Pages edge deployment)
- **Styling**: Tailwind CSS v4 with custom neo-brutalist semantic design tokens
- **In-Browser Libraries**:
  - `pdf-lib` for client-side PDF document manipulation
  - `qrcode` for vector QR code rendering
  - `marked` + `dompurify` for secure client-side Markdown previewing
  - Native `Crypto.subtle` for AES-GCM and SHA hashing
  - Native HTML5 `Canvas` and `AudioContext` for media and sound generation
- **Testing**: [Vitest](https://vitest.dev/) with 100% pass rate across all tool modules and routing

## 🚀 Getting Started

### Prerequisites
- Node.js 20+ or Bun installed on your machine.

### Installation
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/tinytools.git
cd tinytools

# Install dependencies
npm install
```

### Local Development
```bash
# Start local dev server (default port: 8080)
npm run dev
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

### Run Tests
```bash
# Run unit and integration tests
npm test
```

### Production Build
```bash
# Compile client bundle and Cloudflare Workers runtime
npm run build
```

## 🌐 Deploy to Cloudflare Pages (Free Hosting with Custom Domain)

Tiny Tools is pre-configured to deploy on **Cloudflare** for **$0/month** with unlimited bandwidth:

1. Push your repository to **GitHub**:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/tinytools.git
   git branch -M main
   git push -u origin main
   ```
2. In [Cloudflare Dashboard](https://dash.cloudflare.com):
   - Navigate to **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
   - Select your `tinytools` repository.
   - Configure build settings:
     - **Build command**: `npm run build`
     - **Output directory**: `.output/public`
   - Click **Save and Deploy**.
3. **Add Custom Domain**:
   - In Cloudflare Pages, go to **Custom domains** → **Set up a custom domain**.
   - Enter your domain (e.g. `tinytools.dev` or `tools.yourname.com`).
   - Cloudflare provisions free automated SSL/TLS certificates with zero maintenance!
